# Jóvenes: Igualdad para la diversidad juvenil

[[Mujeres y Jovenes]]

## Accion
Crear sistema de cuidado para madres jóvenes, educación digital rural, fondo de emprendimiento étnico y accesibilidad para jóvenes discapacitados.

## Meta
Cerrar brechas urbanas-rurales, de género y de discapacidad entre jóvenes.
